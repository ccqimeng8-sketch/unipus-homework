# unipus-homework

一个用于 Doubao / 豆包办公模式的 Skill：在 **U校园（Unipus）** 上自动完成指定单元的**必修英语练习**。

> 仅用于本人账号下、已购课程的作业自动化；客观题首次提交即锁定成绩，请先自行核对答案。

## 它能做什么

- 打开课程目录，自动识别带橙色"必修"标记的小节，跳过非必修项、视频引导页、课文文本页和单词卡。
- 逐标签完成：单选（radio）、选词/搭配填空、短语翻译、拖拽配对、Banked cloze、阅读理解、段落翻译等。
- 听力/视频题在本地转写（faster-whisper）或页面内播放后再作答。
- 每个标签独立提交，回目录核对完成图标（`passstyle`）是否全部变蓝。

已验证课程：**《新一代大学英语（提高篇）综合教程 2》**（`courseId=654&school_id=8956&eccId=143590&classId=1058653`）。其他课程把目录 URL 替换成你自己的即可。

## 前置条件

- 豆包办公模式内置浏览器（`browser-use` / `aha_browser_use`）可用。
- 两个站点会话分别独立：`u.unipus.cn`（目录）与 `ucontent.unipus.cn`（做题页）都需要**手动登录一次**；登录态过期时会请你接管浏览器重新登录。
- 可选：本地装 Python 与 `faster-whisper`（仅做听力转写时需要）。

## 安装

把整个文件夹放到你的用户 skills 目录：

```
<workspace>/.user_skills/unipus-homework/
└── SKILL.md
```

重启会话后，豆包会自动加载该 Skill。

## 使用

直接对豆包说，例如：

```
在U校园上把第四单元的必修练习做了
目录：https://u.unipus.cn/user/student/mycourse/catalog?courseId=...
```

或更口语化："刷一下 U校园 Unit 3"。

## 关键约定（踩过的坑）

- **每个标签单独提交**，不是整个活动一次提交；目录图标按标签变蓝。
- 填空题答案用**真实键盘**输入（两步 setter 会在翻页/切标签时丢值）。
- 提交按钮点不动时，用 JS 直接 `button.click()`；先清掉 `z-index≥1000` 的透明遮罩。
- 长视频在页面可见时点一次播放，之后切后台也会继续播完。
- 客观题首次提交即锁定，答案要取题目所需的最短核心词。

完整细节见 [`SKILL.md`](./SKILL.md)。
